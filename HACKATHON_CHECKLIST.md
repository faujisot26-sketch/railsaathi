# Hackathon presentation checklist

## Before the event

- [ ] Confirm this event's submission format, rules, AI-use disclosure, and demo requirements with the organizer.
- [ ] Deploy the static prototype to a public HTTPS URL and check the URL on a second phone.
- [ ] Rehearse the three-minute flow in DEMO_SCRIPT.md.
- [ ] Use fictional details only; clear any sample trip before a public screen recording.
- [ ] Capture a short demo video and two screenshots.
- [ ] Verify the README, architecture diagram, and known limitations are easy to find.
- [ ] Ask one passenger to try it and record their feedback with permission.
- [ ] Choose and add an open-source license only after deciding the terms.

## During judging

- [ ] Start with one passenger and one concrete station-side problem.
- [ ] Show Add trip → saved card → berth guide → privacy/offline boundary.
- [ ] Describe current working behavior separately from the production roadmap.
- [ ] Explain why no live status is displayed yet: no licensed feed is connected.
- [ ] End with one measurable next step from real passenger feedback.
