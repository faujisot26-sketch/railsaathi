# RailSaathi

RailSaathi is an early, shareable prototype for an Indian train travel companion. It demonstrates the interface for train lookup, berth guidance, and a sample ticket view.

## Current status

This repository contains a front-end prototype, not a production railway service or a Play Store app. Train information and ticket details shown by the prototype are illustrative demo content. It does not connect to live train feeds, IRCTC, PNR services, phone OTP, or a user account. Do not enter real passenger, ticket, or PNR details.

## Preview

Open `index.html` in a browser. No installation is needed.

## Planned production work

- Secure, authorized data provider for train schedules and live running updates.
- Authorized PNR enquiry, with clear consent and minimal retention of passenger data.
- Android application, backend, phone sign-in, privacy policy, and account deletion.
- Play Store testing, release signing, and store listing.

See [PRODUCTION_REQUIREMENTS.md](PRODUCTION_REQUIREMENTS.md) for the data, privacy, and release requirements. Live services require a provider agreement and credentials; never commit secrets to this repository.
